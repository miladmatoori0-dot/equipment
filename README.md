# ثبت تجهیزات افراد

اپلیکیشن وب برای ثبت اطلاعات تجهیزات کامپیوتری هر فرد (کیس، مانیتور، پرینتر، …)

## نحوه استفاده
- لینک اپ: `https://USERNAME.github.io/equipment/`
- روی گوشی در Chrome باز کن → Add to Home screen
- کاملاً آفلاین کار می‌کند

## فایل‌ها
- `index.html` — اپ اصلی
- `manifest.json` — تنظیمات PWA
- `sw.js` — آفلاین‌سازی
